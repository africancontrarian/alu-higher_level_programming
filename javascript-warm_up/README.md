# JavaScript - Warm up

Introductory Node.js scripts covering variables, arguments, loops, functions, modules, and objects.

## Requirements
- Ubuntu 20.04
- Node.js 14.x
- Semistandard (AirBnB style with some differences)
- All scripts start with `#!/usr/bin/node` and are executable

## Tasks
- 0: Print "JavaScript is amazing"
- 1: Print three languages
- 2: Count process arguments
- 3: Print first argument
- 4: Concatenate two arguments
- 5: Convert argument to integer
- 6: Loop over language strings
- 7: Print "C is fun" x times
- 8: Print a square of X
- 9: Add two integers
- 10: Factorial (recursive)
- 11: Second biggest integer
- 12: Update object value
- 13: Export an add function
- 100: Force const variable change
- 101: Call a function x times
- 102: Increment then call
- 103: Add incr method to object
