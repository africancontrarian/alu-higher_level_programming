# JavaScript - Web scraping

Node.js scripts for reading/writing files and scraping APIs with the `request` module.

## Requirements
- Ubuntu 20.04
- Node.js 14.x
- Semistandard (AirBnB style with some differences)
- `request` module
- All scripts start with `#!/usr/bin/node` and are executable

## Tasks
- 0: Read and print a file
- 1: Write a string to a file
- 2: Display the status code of a GET request
- 3: Print Star Wars film title by ID
- 4: Count films featuring Wedge Antilles (character 18)
- 5: Store the body of a GET request in a file
- 6: Compute completed tasks by user ID
- 100: Print all characters of a Star Wars film
- 101: Print Star Wars characters in film order
