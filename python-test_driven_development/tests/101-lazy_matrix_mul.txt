The ``101-lazy_matrix_mul`` module
======================================

This module defines ``lazy_matrix_mul``, a function that validates
two matrices the same way ``matrix_mul`` does, then delegates the
actual multiplication to NumPy's ``matmul``.

Import the function
--------------------

    >>> lazy_matrix_mul = __import__('101-lazy_matrix_mul').lazy_matrix_mul

Basic usage
------------

    >>> print(lazy_matrix_mul([[1, 2], [3, 4]], [[1, 2], [3, 4]]))
    [[ 7 10]
     [15 22]]

    >>> print(lazy_matrix_mul([[1, 2]], [[3, 4], [5, 6]]))
    [[13 16]]

    >>> print(lazy_matrix_mul([[1, 0], [0, 1]], [[5, 6], [7, 8]]))
    [[5 6]
     [7 8]]

    >>> print(lazy_matrix_mul([[-1, 2]], [[3], [-4]]))
    [[-11]]

Works with floats
--------------------

    >>> print(lazy_matrix_mul([[1.5, 2.5]], [[2], [2]]))
    [[8.]]

The original inputs are not mutated
---------------------------------------

    >>> m_a = [[1, 2], [3, 4]]
    >>> m_b = [[1, 2], [3, 4]]
    >>> result = lazy_matrix_mul(m_a, m_b)
    >>> m_a
    [[1, 2], [3, 4]]
    >>> m_b
    [[1, 2], [3, 4]]
