The ``101-lazy_matrix_mul`` module
======================================

This module defines ``lazy_matrix_mul``, a function that multiplies
two matrices by delegating directly to NumPy's ``matmul``. NumPy
itself is responsible for validating the inputs and raising its own
errors; the exact wording of those errors comes from the NumPy
version installed (this project pins ``numpy==1.15.0``).

Import the function
--------------------

    >>> lazy_matrix_mul = __import__('101-lazy_matrix_mul').lazy_matrix_mul

Basic usage
------------

    >>> print(lazy_matrix_mul([[1, 2], [3, 4]], [[1, 2], [3, 4]]))
    [[ 7 10]
     [15 22]]

    >>> print(lazy_matrix_mul([[1, 2]], [[3, 4], [5, 6]]))
    [[13 16]]

    >>> print(lazy_matrix_mul([[1, 0], [0, 1]], [[5, 6], [7, 8]]))
    [[5 6]
     [7 8]]

    >>> print(lazy_matrix_mul([[-1, 2]], [[3], [-4]]))
    [[-11]]

Works with floats
--------------------

    >>> print(lazy_matrix_mul([[1.5, 2.5]], [[2], [2]]))
    [[8.]]

The original inputs are not mutated
---------------------------------------

    >>> m_a = [[1, 2], [3, 4]]
    >>> m_b = [[1, 2], [3, 4]]
    >>> result = lazy_matrix_mul(m_a, m_b)
    >>> m_a
    [[1, 2], [3, 4]]
    >>> m_b
    [[1, 2], [3, 4]]

Both ``m_a`` and ``m_b`` are required arguments
-----------------------------------------------------

``lazy_matrix_mul`` has no default values, so calling it without
both arguments raises Python's own ``TypeError``.

    >>> lazy_matrix_mul([[1, 2]])
    Traceback (most recent call last):
    TypeError: lazy_matrix_mul() missing 1 required positional argument: 'm_b'

    >>> lazy_matrix_mul()
    Traceback (most recent call last):
    TypeError: lazy_matrix_mul() missing 2 required positional arguments: 'm_a' and 'm_b'
