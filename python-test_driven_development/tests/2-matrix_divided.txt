The ``2-matrix_divided`` module
==================================

This module defines ``matrix_divided``, a function that returns a
new matrix where every element has been divided by a given number
and rounded to 2 decimal places.

Import the function
--------------------

    >>> matrix_divided = __import__('2-matrix_divided').matrix_divided

Basic usage
------------

    >>> matrix = [[1, 2, 3], [4, 5, 6]]
    >>> matrix_divided(matrix, 3)
    [[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]

The original matrix is not mutated
-------------------------------------

    >>> matrix
    [[1, 2, 3], [4, 5, 6]]

Works with floats in the matrix and/or as the divisor
----------------------------------------------------------

    >>> matrix_divided([[1.0, 2.0], [3.0, 4.0]], 2)
    [[0.5, 1.0], [1.5, 2.0]]

    >>> matrix_divided([[2, 4], [6, 8]], 2.0)
    [[1.0, 2.0], [3.0, 4.0]]

Works with negative numbers and a single-element matrix
-------------------------------------------------------------

    >>> matrix_divided([[-3, 6]], 3)
    [[-1.0, 2.0]]

    >>> matrix_divided([[5]], 2)
    [[2.5]]

Dividing by an infinite ``div`` rounds every finite element to 0.0
------------------------------------------------------------------------

``div`` is a genuine float, and no element ever equals it, so no
error is raised: every finite element divided by infinity rounds to
0.0.

    >>> matrix_divided([[1, 2], [3, 4]], float('inf'))
    [[0.0, 0.0], [0.0, 0.0]]

Both ``matrix`` and ``div`` are required arguments
--------------------------------------------------------

``matrix_divided`` has no default values, so calling it without
both arguments raises Python's own ``TypeError``.
