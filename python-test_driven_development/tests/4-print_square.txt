The ``4-print_square`` module
================================

This module defines ``print_square``, a function that prints a
square made of the '#' character, one row of ``size`` characters at
a time.

Import the function
--------------------

    >>> print_square = __import__('4-print_square').print_square

Basic usage
------------

    >>> print_square(4)
    ####
    ####
    ####
    ####

    >>> print_square(1)
    #

A size of 0 prints nothing
-----------------------------

    >>> print_square(0)
