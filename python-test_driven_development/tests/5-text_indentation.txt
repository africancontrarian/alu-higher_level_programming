The ``5-text_indentation`` module
====================================

This module defines ``text_indentation``, a function that prints a
block of text, inserting two new lines after every '.', '?', and ':'
character, with no leading or trailing spaces on any printed line.

Import the function
--------------------

    >>> text_indentation = __import__('5-text_indentation').text_indentation

Basic usage with a short sentence
-------------------------------------

    >>> text_indentation("Hello. World? Bye:end")
    Hello.
    <BLANKLINE>
    World?
    <BLANKLINE>
    Bye:
    <BLANKLINE>
    end

Edge cases
------------

An empty string prints nothing:

    >>> text_indentation("")

A string made only of spaces prints nothing:

    >>> text_indentation("     ")

A string with no special characters is printed as-is, with no
trailing newline added by the function itself:

    >>> text_indentation("Hi")
    Hi

A lone special character:

    >>> text_indentation(".")
    .
    <BLANKLINE>

----------------------------
