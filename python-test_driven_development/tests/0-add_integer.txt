The ``0-add_integer`` module
=============================

This module defines ``add_integer``, a function that adds two values
together after validating and, if needed, casting them to integers.

Import the function
--------------------

    >>> add_integer = __import__('0-add_integer').add_integer

Basic addition
---------------

    >>> add_integer(1, 2)
    3

    >>> add_integer(100, -2)
    98

    >>> add_integer(0, 0)
    0

    >>> add_integer(-1, -2)
    -3

Using the default value for ``b``
-----------------------------------

    >>> add_integer(2)
    100

Floats are cast to int (truncated) before adding
---------------------------------------------------

    >>> add_integer(100.3, -2)
    98

    >>> add_integer(1.9, 2.9)
    3

    >>> add_integer(-1.9, -2.9)
    -3

    >>> add_integer(3.9)
    101
