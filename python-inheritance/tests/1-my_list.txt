The ``1-my_list`` module
=========================

Using ``MyList``
-----------------

Load the class:

    >>> MyList = __import__('1-my_list').MyList

Create a new, empty instance:

    >>> my_list = MyList()
    >>> my_list
    []

``print_sorted`` on an empty list prints an empty list:

    >>> my_list.print_sorted()
    []

Add a few integers in an unsorted order:

    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Calling ``print_sorted`` displays the values in ascending order:

    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

The original order of the list itself stays untouched:

    >>> print(my_list)
    [1, 4, 2, 3, 5]

Calling ``print_sorted`` again on an already-sorted list changes
nothing:

    >>> sorted_list = MyList()
    >>> sorted_list.append(1)
    >>> sorted_list.append(2)
    >>> sorted_list.append(3)
    >>> sorted_list.print_sorted()
    [1, 2, 3]

Negative numbers are sorted correctly, mixed with positive ones:

    >>> mixed_list = MyList()
    >>> mixed_list.append(-3)
    >>> mixed_list.append(10)
    >>> mixed_list.append(-7)
    >>> mixed_list.append(0)
    >>> mixed_list.append(5)
    >>> mixed_list.print_sorted()
    [-7, -3, 0, 5, 10]
    >>> print(mixed_list)
    [-3, 10, -7, 0, 5]

Negative numbers are also sorted correctly on their own:

    >>> negative_list = MyList()
    >>> negative_list.append(-1)
    >>> negative_list.append(-5)
    >>> negative_list.append(-2)
    >>> negative_list.print_sorted()
    [-5, -2, -1]

``MyList`` still behaves like a normal list:

    >>> len(my_list)
    5
    >>> isinstance(my_list, list)
    True
