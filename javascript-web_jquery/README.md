# JavaScript - Web jQuery

Front-end JavaScript scripts using jQuery to manipulate the DOM, handle events, and fetch data from APIs.

## Requirements
- Ubuntu 20.04
- jQuery 3.x via CDN in HTML fixtures
- Semistandard (AirBnB style with some differences)
- No `var` keyword; use `const` / `let`
- Semicolons required

## Tasks
- 0: Update header color with document.querySelector
- 1: Update header color with jQuery
- 2: Click to turn header red
- 3: Add red class to header on click
- 4: Toggle red/green class on header
- 5: Add list item on click
- 6: Update header text on click
- 7: Fetch and display Star Wars character name
- 8: List all Star Wars movie titles
- 9: Fetch and display HelloSalut greeting (from head)
- 100: Update header color after DOMContentLoaded (no jQuery)
- 101: Add, remove, and clear list items
- 102: Translate HelloSalut by language code
- 103: Translate on button click or Enter key
